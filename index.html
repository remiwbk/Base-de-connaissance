La procédure en 6 étapes

On ne travaille jamais directement sur main. Tout passe par la branche test.

1

Récupérer le projet

git clone URL_DU_REPO
cd nom-du-repo
2

Créer la branche test (locale)

git checkout -b test

Si elle existe déjà : git checkout test puis git pull origin test

3

Ajouter son PDF

Copier le fichier dans le dossier pdf/, puis l'ajouter à la liste dans pdfs.js.

git add pdf/mon-fichier.pdf pdfs.js
git commit -m "Ajout du PDF mon-fichier"
4

Envoyer sur la branche distante

git push -u origin test
5

Faire valider (Pull Request)

Sur GitHub : Compare & pull request de test vers main. Un autre membre relit et approuve.

6

Fusionner dans main

Après validation : Merge pull request. Le site se met à jour tout seul. Chacun resynchronise ensuite :

git checkout main
git pull origin main
💡 Commandes utiles 
git status          # état des fichiers
git log --oneline   # historique
git branch -a       # toutes les branches
git pull            # récupérer les changements
git diff            # voir les modifications
